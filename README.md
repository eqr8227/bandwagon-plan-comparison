## 线路怎么选：GIA、GT 和普通线路差在哪

三档线路的核心区别在于晚高峰的稳定性。CN2 GIA 是电信 CN2 GIA 直连，三网表现最好，价格也最高；CN2 GT 只保证走 CN2 网络，电信用户比普通线路强，但高峰期不如 GIA 稳；KVM 走普通线路，胜在便宜。

对应到机房选择：面向国内建站优先 DC6 CN2 GIA-E，三网直连、晚高峰稳定；在意硬件性能选 DC9，AMD CPU 加 NVMe SSD；联通用户可以重点试日本大阪软银 JPOS_1，延迟和丢包都控制得不错，讲究一点的还有荷兰 EUNL_9 的 9929 线路。停留在 KVM 和 CN2 系列的话，DC8 晚上通常比 DC3 稳一点，但实际效果跟地区有关，建议到手先测速再决定要不要切机房。

## 常见问题

**建站选哪个套餐和机房？** CN2 GIA-E 1GB（年付 $169.99）起步，机房优先 DC6；联通用户可以切到大阪软银试试。预算实在紧张，CN2（GT）$49.99/年 也能建站，机房选 DC8，晚高峰相对稳一些。

**能装 Windows 吗？** 不能直接装。搬瓦工只提供 Linux 系统镜像，想用图形界面可以通过 VNC 安装 Linux 桌面环境。

**IP 被封了怎么办？** 可以申请新 IP 或重新购买一台。特别怕 IP 出问题的对外业务，电商 SLA 套餐每两周能免费换一次 IP，是唯一有这个待遇的系列。

**流量用超了怎么办？** 等下个月流量自动重置，或在后台补差价升级到更大流量的套餐。

**老的 OpenVZ 套餐还能续费吗？** 不能，OpenVZ 架构已下架，老用户只能迁移到 KVM 架构。
